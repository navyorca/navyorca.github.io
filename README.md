# Like next post feed

A personal Bluesky feed. It lists the first non-reply post that someone publishes within one hour of liking one of my posts.

GitHub Actions rebuilds the static feed files every 15 minutes from public Bluesky APIs.

The next-post rule comes from [RepostNextPost](https://github.com/dolciss/rp-next-post). The static hosting idea comes from [static-bsky-feed](https://github.com/Raicuparta/static-bsky-feed).
